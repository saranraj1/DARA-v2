## Analysis Instructions

Think step by step. Be precise and specific.

Step 1 - IMMEDIATE CAUSE: What exact expression/line causes the error right now?
Step 2 - ROOT CAUSE: What deeper architectural or logic flaw allowed this to happen?
Step 3 - CONTRIBUTING FACTORS: What conditions made this likely (e.g. missing null checks, race condition, bad deployment)?
Step 4 - FILES TO CHANGE: Which specific files need to be modified to fix this?
Step 5 - STRATEGY: Choose the fix strategy:
  - "template_based": a known pattern, can apply a simple template fix
  - "llm_single_file": requires LLM to fix a single file
  - "llm_multi_file": requires LLM to fix multiple files
  - "human_escalation": too complex, requires human review

Step 6 - CONFIDENCE: How confident are you? (0.0 = pure guess, 1.0 = certain)
  - 0.9-1.0: Complete stack trace, full code context, seen this pattern before
  - 0.7-0.9: Good stack trace, partial context
  - 0.5-0.7: Partial stack trace or unfamiliar pattern
  - 0.0-0.5: Very little context, many unknowns

After reasoning, output ONLY a JSON object:
{
  "immediate_cause": "exact description of what throws the error",
  "root_cause": "deeper architectural or logic reason",
  "contributing_factors": ["factor 1", "factor 2"],
  "confidence": 0.00,
  "evidence_quality": "high|medium|low",
  "files_to_change": ["path/to/file.py"],
  "suggested_strategy": "template_based|llm_single_file|llm_multi_file|human_escalation",
  "reasoning_trace": "your step-by-step reasoning"
}
